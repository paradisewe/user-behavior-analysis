# 核心分析结果

## 数据规模

| 指标 | 数值 |
|------|------|
| 总行为数 | 4,985,162 |
| 独立用户数（UV） | 49,326 |
| 商品数 | 1,101,718 |
| 类目数 | 7,436 |

## 行为类型分布

| 行为 | 占比 |
|------|------|
| 浏览（pv） | 89.57% |
| 加购（cart） | 5.49% |
| 收藏（fav） | 2.93% |
| 购买（buy） | 2.01% |

浏览占比接近 90%，购买仅占 2%，符合典型的电商「漏斗型」行为分布。

## 用户级漏斗

只要用户**曾经**有过该行为即计入（反映用户覆盖面）：

| 阶段 | 用户数 | 相对浏览 |
|------|--------|---------|
| 浏览 | 49,157 | 100.00% |
| 收藏 | 19,562 | 39.79% |
| 加购 | 36,481 | 74.21% |
| 购买 | 33,337 | 67.82% |

**注意**：用户级漏斗的转化率天然偏高——只要用户曾经有过该行为即计入，无法反映真实商品转化效率。

## 用户-商品级顺序漏斗（真实转化）

以「同一用户在同一商品上的先后行为」为口径，反映真实商品转化效率：

| 阶段 | 数量 | 转化率 |
|------|------|--------|
| 浏览（pv） | 3,493,068 对 | 100.00% |
| 加购（cart） | 37,228 对 | 1.07% |
| 购买（buy） | 49,091 对 | 1.41% |

**关键洞察**：

- 普通浏览用户 → 购买：**1.41%**
- 已加购用户 → 购买：**5.98%**
- **加购用户的购买转化率是普通浏览用户的 4 倍**

**商业应用**：营销资源应优先投向「促进加购」环节（如加购有礼、加购提醒），而非直接促进购买。

## DAU 与购买趋势

- 11-25 至 12-01：DAU 稳定在 3.5~3.8 万（抽样数据）
- 12-02（周六）：DAU 峰值，较前 7 天均值上涨约 30%
- 12-03：DAU 与 12-02 持平
- 购买用户数与购买行为数在 12-02 同步冲顶

## 复购分析

- 总购买用户数：33,337
- 复购用户数：约 21,939
- **复购率：65.81%**（Python）/ 66.01%（SQL 全量）

## 用户分层结构

| 行为深度 | 用户数（样本） | 占比 |
|---------|--------------|------|
| 已购买 | 33,337 | 67.8% |
| 加购未购买 | 10,416 | 21.1% |
| 仅浏览 | 3,033 | 6.2% |
| 仅收藏 | 2,540 | 5.2% |

**已购买用户中**：
- 单次购买：约 34%
- 2~3 次：约 38%
- 4 次以上：约 28%

## 时间分布

24 小时行为分布呈现典型特征：

- 低谷：凌晨 3~4 点
- 次高峰：凌晨 0 点
- **主高峰：晚上 21~22 点**

周末购买时段与工作日有显著差异：周末凌晨 2~4 点、早上 6 点出现明显高峰。
