# 数据质量报告

## 数据源

阿里天池「淘宝用户行为数据集」（UserBehavior.csv），原始大小约 3.42 GB。

| 项目 | 值 |
|------|-----|
| 原始行数 | 100,150,807 |
| 原始用户数 | 987,994 |
| 时间戳格式 | Unix 秒级整数 |
| 列数 | 5 列（无表头） |

## 数据清洗步骤

### 1. 列数校验

每行必须是 5 列。列数不对的行直接剔除。

### 2. 去空

关键列（user_id、item_id、category_id、behavior_type、timestamp）不能为空。

### 3. 行为类型规范化

- 统一转小写
- 去除首尾空格
- 只保留 pv / fav / cart / buy 四种合法值

### 4. 时间戳转换

Unix 秒 → 北京时间（UTC+8）：

```python
df["timestamp"] = pd.to_datetime(df["timestamp"], unit="s", utc=True).dt.tz_convert("Asia/Shanghai").dt.tz_localize(None)
```

**为什么加 8 小时**：天池原始时间戳是 UTC 时间，需转成北京时间才能得到正确的日期和小时分布。

### 5. 时间范围过滤

只保留 **2017-11-25 ~ 2017-12-03**（天池数据集的核心窗口）。

### 6. 类型规范化

| 列 | 类型 | 原因 |
|----|------|------|
| user_id | int64 | 数值比较快 |
| item_id | int64 | 同上 |
| category_id | int64 | 同上 |
| behavior_type | category | 只有 4 个取值，节省内存 |
| timestamp | datetime64 | 时间分析需要 |

## 清洗前后对比

| 阶段 | 行数 |
|------|------|
| 抽样后 | 4,987,673 |
| 去重后 | 4,987,669 |
| 时间过滤后 | 约 4,985,162 |
| 类型规范化后 | 4,985,162 |

内存占用：约 193 MB。

## 数据质量结论

- 天池数据集**整体质量较高**，脏数据很少
- 去重删除约 4 行
- 时间过滤删除约 2,500 行（大部分是边界日期数据）
- 最终数据干净、结构化、可用于分析
