# 轻量商品推荐原型（类目协同过滤）

Plan.md 深化方向 #9 的**轻量版**（原方向定级低优先级）。重点在**评估方法论**，
不在模型效果本身。

## 方法

- **粒度**：类目级（商品 ID 脱敏无业务含义，类目共现矩阵小、可解释）
- **CF**：item-based，训练期购物篮内类目共现的 lift 打分，
  候选分 = Σ lift(历史类目 → 候选)；共现对要求 ≥3 个购物篮（过滤长尾偶然共现）；
  CF 候选不足时用热门类目补齐
- **基线**：热门推荐（训练期购买用户数 Top 类目）
- **评估**：时间切分（训练 11-25~12-01 / 测试 12-02~12-03），对测试期发生
  「新类目购买」的用户算 Precision@10 / Recall@10

## 结果（诚实版：CF 输给基线）

| 指标 | 类目 CF | 热门基线 |
|------|---------|---------|
| Precision@10 | 0.93% | 1.93% |
| Recall@10 | 6.16% | 12.77% |

- 评估用户 9,586 人（排除冷启动新用户），训练期有效购物篮 15,813、类目对 69,032
- 未过滤长尾时 CF 的 Precision 只有 0.04%（高 lift 偶然共现主导打分）；
  加 ≥3 篮子过滤后提升 23 倍到 0.93%，但仍只有热门基线的 0.48 倍
- **结论**：9 天窗口 + 5% 抽样的共现信号太稀疏，短窗口电商数据上
  热门推荐是很难打的基线。要做出正向 CF，需要更长窗口（≥1 个月）与全量数据。
  这个负结果与 Plan.md 把该方向定为「低优先级」的判断一致。
