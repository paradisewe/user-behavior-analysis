# Dashboard 设计说明

项目提供两个版本的 Dashboard，覆盖不同的使用场景。

## Excel Dashboard（静态）

**位置**：`python/reports/dashboard.xlsx`

**生成方式**：

```bash
python dashboard/build_dashboard.py
```

**内容**：7 个 Sheet

| Sheet | 内容 |
|-------|------|
| 概览 | 核心 KPI + 行为分布 + 漏斗 + 趋势预览 |
| 行为分布 | 饼图 + 柱状图 |
| 转化漏斗 | 漏斗条形图 |
| 用户趋势 | 三线折线图（DAU、购买用户、购买行为） |
| 时间分布 | 24 小时行为分布折线图 |
| 用户分层 | 堆叠柱状图 |
| 类目 TOP10 | 横向条形图 |

**技术实现**：xlsxwriter

**特点**：

- Sparkline 迷你趋势图
- 卡片式 KPI 布局
- 业务方可直接打开使用

## Streamlit Dashboard（交互式）

**位置**：`python/dashboard/app.py`

**启动方式**：

```bash
pip install streamlit plotly
streamlit run dashboard/app.py
```

浏览器打开 `http://localhost:8501`。

**核心功能**：

| 功能 | 说明 |
|------|------|
| 侧边栏筛选 | 按日期范围、行为类型实时筛选，所有图表联动更新 |
| 5 个 Tab | 行为分布 / 转化漏斗 / 用户趋势 / 时间分布 / 用户分层 |
| Plotly 交互 | 悬停查看数值、框选缩放、双击重置 |
| 数据缓存 | @st.cache_data 只加载一次，Tab 切换秒响应 |
| KPI 卡片 | 8 个核心指标（规模 + 效率） |

## 为什么做两个版本

| 版本 | 优势 |
|------|------|
| Excel | 给业务方交付，无需编程环境 |
| Streamlit | 给技术同学演示，可交互探索 |
