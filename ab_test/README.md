# A/B 测试框架（基于历史数据的模拟实验）

> ⚠️ **表述红线**：这是**基于历史数据的模拟实验**，用于完整展示 A/B 测试方法论
> （实验设计 → 随机化 → 检验 → AA 校准），**不是真实在线实验**。

## 模拟场景

双 12 前给「加购未购买」用户推送提醒，观察后续购买转化是否提升。

| 口径 | 定义 |
|------|------|
| 实验总体 | 2017-11-25 ~ 12-01 有加购、且截至 12-01 尚未购买的用户（11,836 人） |
| 观测结局 | 12-02 ~ 12-03 是否购买（历史真实结局作为基线） |
| 基线转化率 p0 | **25.38%**（双 12 前购买意愿本身在走高） |
| 干预效应 | 模拟注入（历史数据不含干预）：处理组非转化用户以 δ/(1−p0) 概率翻转为转化，期望提升恰为 δ |

## 文件说明

| 文件 | 内容 |
|------|------|
| `ab_design.py` | 实验设计：总体与基线、给定 MDE 所需样本量、现有总体能检测的最小效应 |
| `ab_simulation.py` | 模拟执行：SRM 检查 → 效应注入 → 两比例 z 检验 → AA 校准 |
| `reports/ab_design_summary.csv` | 设计摘要 |
| `reports/ab_sim_summary.csv` | 200 次模拟校准结果 |
| `reports/ab_calibration.png` | 检出率（含假阳性线）与 CI 覆盖率图 |

## 核心结果

**实验设计（α=0.05，power=0.8）**：现有总体每组 5,918 人，能检测的最小绝对提升
**MDE = 2.27pp（相对提升 8.9%）**；想检测 1pp 需要每组约 3 万人，当前总体不够——
这就是"先做功效分析再上实验"的意义。

**框架校准（200 次模拟）**：

| 注入 δ | 检出率 | 95% CI 覆盖率 |
|--------|--------|--------------|
| 0（AA 实验） | **4.5%**（≈理论假阳性 5%） | 95.5% |
| +1pp | 27.5% | 96.5% |
| +2pp | 66.5% | 94.5% |
| +5pp | 100% | 92.0% |

- AA 实验假阳性率 4.5%，与理论值 5% 吻合 → 检验流程校准正确
- δ=2pp 的检出率 66.5%，与设计阶段 MDE=2.27pp@80% 功效的推算一致
- 代表性实验（δ=+2pp）：估计提升 +1.81pp，95% CI [+0.22pp, +3.40pp]，p=0.025，显著

## 复现

```bash
python ab_design.py       # 实验设计与功效分析
python ab_simulation.py   # 模拟执行与校准（约 1 分钟）
```
